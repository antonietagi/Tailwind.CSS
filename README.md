# Tela de Login com Tailwind CSS 🌸

Este projeto consiste em uma **tela de login responsiva**, desenvolvida com **HTML** e **Tailwind CSS**, com foco no estudo de estilização utilitária e responsividade.

O layout simula uma página de acesso para pedidos de uma confeitaria, com formulário centralizado e imagem ilustrativa em telas maiores.

---

## 🎯 Objetivo do projeto

- Praticar o uso do **Tailwind CSS**
- Trabalhar com **layouts responsivos** (mobile e desktop)
- Utilizar classes utilitárias para estilização rápida
- Desenvolver uma interface simples e organizada

---

## 🛠 Tecnologias utilizadas

- HTML5  
- Tailwind CSS  

---

## 📱 Responsividade

- Em telas menores, o layout prioriza o formulário de login  
- Em telas médias e grandes, a imagem lateral é exibida junto ao formulário
